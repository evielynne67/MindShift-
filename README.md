# MindShift

MindShift is a static, student-friendly website created for MYP 5 Design, Unit 1: **The Impact of Lifting Others Up**. It helps students understand how sleep, screen habits, stress, and mental wellbeing are connected, while promoting healthy, practical action.

The site is designed to be calm, accessible, and easy to navigate, with clear language and supportive visuals.

## Project goal

MindShift explains:
- how brain habits and dopamine influence scrolling behaviour
- why sleep is essential for learning, mood, and focus
- how screens can affect rest and wellbeing
- how to build small, realistic routines that help students feel more in control

## Features

- Responsive mobile-first layout
- Clean landing page and section-based storytelling
- Accessible navigation, semantic structure, and skip link
- Clear explanation pages for brain science, sleep, screens, and mental health
- Practical “small change” advice for real-life routines
- Curated links to reliable health and wellbeing resources
- Lightweight static website with no backend required
- Privacy-focused design: no accounts, cookies, analytics, or server-side tracking

## Run locally

You can open the page directly in a browser, or run a local static server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Publish publicly with GitHub Pages

1. Push this project to a GitHub repository.
2. Open the repository on GitHub.
3. Go to **Settings** → **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the **main** branch and the **/root** folder.
6. Save the settings.
7. GitHub will provide a public URL similar to:

```text
https://USERNAME.github.io/REPOSITORY_NAME/
```

For this project, the expected format is:

```text
https://evielynne67.github.io/MindShift/
```

## Notes

This site is intentionally static and does not require a build process or database. It is suitable for simple public hosting on GitHub Pages.
